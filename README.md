## 🚀 Projeto em destaque

<a href="https://github.com/arthwr14/hyperium-launcher">
  <img src="https://raw.githubusercontent.com/arthwr14/hyperium-launcher/main/docs/assets/banner.png" alt="Hyperium Launcher" width="100%">
</a>

**[Hyperium Launcher](https://github.com/arthwr14/hyperium-launcher)** é um client de PvP para Minecraft 1.8.9 com mais de 80 mods de PvP, HUD e desempenho, já configurados de fábrica. É grátis para Windows, macOS e Linux.

- Launcher em **Electron + TypeScript**: login Microsoft, download automático do Java e do Minecraft, atualizações automáticas
- Client em **Java**: mods de PvP, editor de HUD, OptiFine integrado e texturas novas no 1.8.9
