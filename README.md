## 🚀 Featured project

<a href="https://github.com/arthwr14/hyperium-launcher">
  <img src="https://raw.githubusercontent.com/arthwr14/hyperium-launcher/main/docs/assets/banner.png" alt="Hyperium Launcher" width="100%">
</a>

**[Hyperium Launcher](https://github.com/arthwr14/hyperium-launcher)** is a PvP client for Minecraft 1.8.9 with 80+ PvP, HUD and performance mods, configured out of the box. Free for Windows, macOS and Linux.

- Launcher built with **Electron + TypeScript**: Microsoft sign-in, automatic Java and Minecraft downloads, auto-updates
- Client written in **Java**: PvP mods, HUD editor, built-in OptiFine and modern textures on 1.8.9
